# 隐私与初始化时机

应用负责展示隐私说明、取得和保存真实同意记录，并决定何时使用友盟服务。库不维护用户同意状态。

取得授权后一次调用 `initializeUmeng(config)`。Android 厂商要求的 preInit 与 init 在该调用内部按顺序执行；iOS 注册配置与初始化按真实厂商接口执行。导入包、渲染面板或接收宿主回调不会代替该调用。

配置与密钥不进入日志、模型输入或分享结果。配置开始初始化后被锁定；失败由原调用接收，只有后续明确调用才尝试恢复。厂商异常造成初始化副作用不可判断时，原生保持错误并要求重启。
